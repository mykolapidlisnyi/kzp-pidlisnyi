## Призначення програми

Консольний застосунок призначений для зчитування, валідації та статистичної обробки записів про абонементи клієнтів **тренажерного залу** із CSV-файлів у кодуванні UTF-8.

### Формат вхідних даних (`data/input.csv`)
Файл не містить заголовка; поля розділяються крапкою з комою (`;`) у порядку:
`client;plan;months;visits;price`

| Поле | Тип | Правило валідації |
|---|---|---|
| `client` | `String` | Непорожній рядок (ім'я та прізвище клієнта) |
| `plan` | `String` | Непорожній рядок (назва/тип абонемента) |
| `months` | `int` | Ціле число більше нуля (`> 0`) |
| `visits` | `int` | Ціле невід'ємне число (`>= 0`) |
| `price` | `double` | Скінченне число більше нуля (`Double.isFinite(price) && price > 0.0`) |

### Обчислювані показники
1. **Середня кількість відвідувань** на один абонемент (точність до 2 знаків).
2. **Загальний виторг** (сума вартостей усіх коректних абонементів у грн).
3. **Найдовший абонемент** (клієнт і план із максимальною тривалістю в місяцях).
4. **Найпопулярніший абонемент** (назва плану з найбільшою кількістю оформлень).

## Запуск програми

Для коректного відображення українських символів у Windows PowerShell перед запуском увімкніть UTF-8:
```powershell
chcp 65001
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

### Основні режими CLI
```powershell
# Показати довідку
java "-Dfile.encoding=UTF-8" -jar target/lab01-pidlisnyi-1.0.0-all.jar --help

# Вивести версію програми
java "-Dfile.encoding=UTF-8" -jar target/lab01-pidlisnyi-1.0.0-all.jar --version

# Обробити вхідний файл та зберегти звіт
java "-Dfile.encoding=UTF-8" -jar target/lab01-pidlisnyi-1.0.0-all.jar --input data/input.csv --output reports/summary.txt
```
