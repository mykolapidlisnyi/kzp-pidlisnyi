## Призначення та архітектура застосунку

Консольний Java-застосунок призначений для зчитування, валідації та статистичної обробки записів про абонементи тренажерного залу із CSV-файлів у кодуванні `UTF-8`[cite: 17].

У межах **Лабораторної роботи № 2** предметну частину проєкту перебудовано за принципами об'єктно-орієнтованого дизайну та інкапсуляції без зміни зовнішньої поведінки та формату звіту[cite: 16]:

### Структура пакету `ua.lpnu.kzp`
* **`GymSubscription.java`** — незмінний (`final`) клас-сутність з інкапсульованими `private final` полями (`client`, `plan`, `months`, `visits`, `price`)[cite: 16]. Усі інваріанти перевіряються безпосередньо в конструкторі (при порушенні викидається `IllegalArgumentException`)[cite: 16]. Містить статичний фабричний метод `fromCsv(String line)` для розбору рядків CSV[cite: 16], геттери, перевизначені методи `equals`, `hashCode` та `toString` із форматуванням чисел через `Locale.ROOT`[cite: 16].
* **`GymSummary.java`** — незмінний запис (`record`) для збереження обчислених підсумкових показників статистики з перевіркою невід'ємності в компактному конструкторі[cite: 16].
* **`Main.java`** — точка входу застосунку, яка відповідає виключно за розбір аргументів CLI, потокове зчитування вхідного файлу з делегуванням парсингу фабриці `GymSubscription.fromCsv(...)`, агрегацію даних у `GymSummary` та вивід звіту в консоль і файл[cite: 16].

## Формат вхідних даних та правила валідації

Вхідний файл (`data/input.csv`) не містить заголовка; поля розділяються крапкою з комою (`;`) у порядку:
`client;plan;months;visits;price`

| Поле | Тип у Java | Інваріанти та правила перевірки (у конструкторі `GymSubscription`) |
|---|---|---|
| `client` | `String` | Непорожній рядок (`client != null && !client.isBlank()`)[cite: 16] |
| `plan` | `String` | Непорожній рядок (`plan != null && !plan.isBlank()`)[cite: 16] |
| `months` | `int` | Ціле число більше нуля (`months > 0`) |
| `visits` | `int` | Ціле невід'ємне число (`visits >= 0`) |
| `price` | `double` | Скінченне додатне число (`Double.isFinite(price) && price > 0.0`)[cite: 16] |

### Обчислювані показники звіту
1. **Середня кількість відвідувань** на один абонемент (дробове значення з двома знаками після крапки).
2. **Загальний виторг** від проданих абонементів у гривнях.
3. **Найдовший абонемент** (клієнт, назва тарифного плану та тривалість у місяцях).
4. **Найпопулярніший абонемент** (назва тарифного плану з найбільшою кількістю оформлень).
